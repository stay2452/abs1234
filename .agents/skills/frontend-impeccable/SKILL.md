# Frontend Impeccable

Use o fluxo visual existente em `.opencode/skills/impeccable` como a fonte de verdade para pedidos de UI. Ele continua no repositorio para que OpenCode e Codex compartilhem a mesma linguagem visual e os mesmos playbooks.

1. Execute `.opencode/skills/impeccable/scripts/impeccable.cmd context` uma vez por sessao, a partir da raiz do projeto.
2. Leia `.opencode/skills/impeccable/SKILL.md` e carregue somente a referencia indicada para o modo pedido (por exemplo, `audit`, `critique`, `polish` ou `adapt`).
3. Preserve o comportamento e os fatos do produto. Nao dispare coleta Apify para verificar uma tela e nao exponha segredos em capturas, logs ou respostas.
4. Antes de editar componentes visuais, leia a referencia `craft-floor.md` indicada pelo fluxo. Valide em passagens limitadas conforme esse playbook e execute as verificacoes proporcionais a alteracao.

Se o launcher ou seus recursos nao puderem ser executados, explique a limitacao antes de editar e siga as regras do projeto em AGENTS.md.
